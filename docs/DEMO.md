# Two-minute walkthrough

Record this against `http://localhost:5173` with the three processes running and `npm run db:seed` already applied.

1. **Sources (20s).** Show the pre-filled CPSC 210 excerpt. Point at the sentence about representation invariants. Click *Save source*, then *Draft questions*. Wait for the live region: "Generated N drafts".
2. **Review queue (50s).** Open the queue. Pick a card. Read one rubric finding out loud if present (catch-all, verbatim, length cue). Edit a stem by a few words, save, then approve. Reject a second item with a note.
3. **Bank (20s).** Show that only the approved item is there. Click *Export Moodle GIFT* and open the file: the rejected item is absent.
4. **Metrics (20s).** Show acceptance rate, median edit distance, duplicate rate. Say that these numbers come from `review_events`, not from the model.
5. **Close (10s).** "The model drafts. The rubric screens. A human writes the bank."

Keep the voiceover under two minutes. Do not narrate the stack; the README does that.
